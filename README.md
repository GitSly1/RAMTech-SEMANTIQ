# RAMTech SEMANTIQ

Managed product repository under the RAMTech Virtual Software Company (RVSC) operating model.

All SEMANTIQ product source, tests, product-specific documentation, and release artifacts belong in this repository. RVSC control-plane logic, cross-project orchestration, company-level governance, and the authoritative RVSC Constitution belong in `GitSly1/RAMTech-RVSC-Control-Center`.

## Governance

SEMANTIQ adopts the RVSC constitutional model through `governance/RVSC_GOVERNANCE.md`.

Development uses bounded work packages, assigned-workspace-only agent authority, verified repository/commit provenance, deterministic validation, independent QA, evidence-backed acceptance, fail-closed security, no direct/transitive agent egress, and governed human-gated promotion.

Improvement is encouraged, but greater capability never silently expands authority. Resolution efficiency and compliance are measured together.
